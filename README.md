# 🩺 DocFinder - Smart Clinic & Appointment System
> A responsive full-stack web application designed to bridge the gap between patients and medical clinics, offering smart appointment scheduling, doctor discovery, and queue management
> 
## Tech Stack :
1-Frontend: React, TypeScript, Tailwind CSS / Bootstrap
2-Backend:Node.js , Express.js
3-Database:MongoDB (Mongoose)
4-Version Control: Git & GitHub

## Core Features : 
- Doctor Directory & Search: Filter doctors by specialty, location, and availability.
- Appointment Booking: Secure and seamless booking management (view, reschedule, cancel).
- Queue Tracking: Real-time queue number and estimated waiting time.
- Admin Dashboard:Ma nage clinic data, doctor registrations, and account verifications.
- Role-Based Access Control:Separate interfaces and permissions for Patients, Doctors, and Admins.
